# 茜特拉莉 2.5D Live 实时交互演示系统

本工程展示了如何将 3D 原生 PMX 骨骼模型与贴图组件，通过轻量级 WebGL / 2.5D 管线无损转换为具有 **Live2D 级生动交互（视线追踪、转头视差、自然呼吸、自动眨眼、表情形态键、大模型指令驱动）** 的开放世界角色。

---

## 🚀 核心特性

1. **零环境依赖与极速加载**：
   - 无需安装 Blender、Live2D Cubism Editor 或 Node.js 后端构建工具。
   - 所有运行时库（Three.js + MMDLoader 等）均已本地化内置在 `libs/` 文件夹中，支持离线秒开。

2. **100% 精准骨骼与贴图保真**：
   - 直接读取 `assets/茜特拉莉_夏日.pmx` 原生 439 根骨骼与 `assets/tex/` 贴图材质。
   - 彻底杜绝纯 2D AI 脑补骨骼造成的扭曲与破皮。

3. **2.5D Live 级生命体交互**：
   - **👀 视线跟随光标 (Gaze Tracking)**：鼠标在屏幕上移动时，头部（Head）、颈部（Neck）与视线实时平滑插值追踪。
   - **✨ 自动眨眼系统 (Auto Blinking)**：带有随机时间间隔与正弦平滑曲线的自然眨眼。
   - **🫁 程序化自然呼吸 (Breathing Cycle)**：脊椎（Spine）骨骼注入正弦波微动，消除机械僵硬感。
   - **🎭 67 组形态键 (Morphs) 实时驱动**：脸红红晕（`恥ずかしい`）、微笑（`笑い`）、傲娇笑（`にやり`）、闭眼、张嘴等。

4. **🤖 SillyTavern / 酒馆大模型动作指令模拟器**：
   - 内置对话气泡与实时说话口型同步（LipSync）；
   - 可一键下发带有情绪与头部姿态的动作指令（如傲娇轻哼、娇羞偏头、惊喜注视）。

---

## 💻 快速运行

双击运行根目录下的 `start.bat`，或者在终端执行：

```bash
python start_demo.py
```

服务启动后将自动在浏览器中打开：`http://localhost:8088/index.html`。
